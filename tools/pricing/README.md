# Competitive Pricing Monitor

Local tool for tracking competitor Airbnb pricing and generating recommendations.

## Quick Start

```bash
# 1. Install dependencies (from project root)
npm install

# 2. Initialize the database
node tools/pricing/scripts/init-db.js

# 3. Add competitors
node tools/pricing/scripts/add-comp.js \
  --unit unit-a \
  --name "Cozy Studio in Condado" \
  --bedrooms 2 --bathrooms 1 \
  --cleaning-fee 45 \
  --neighborhood Condado

# 4. Add price snapshots
node tools/pricing/scripts/add-snapshot.js \
  --comp 1 \
  --date 2026-04-04 --rate 72

# 5. Record your own rates
node tools/pricing/scripts/add-my-rates.js \
  --unit unit-a \
  --date 2026-04-04 --rate 65 \
  --cleaning-fee 40

# 6. Run analysis
node tools/pricing/scripts/analyze.js --unit unit-a --days 30

# 7. Generate reports (markdown + dashboard JSON)
node tools/pricing/scripts/generate-report.js
```

## Conversational Usage (Primary Flow)

Talk to Claude Code naturally:

- *"Add this competitor for Unit A: [details]"*
- *"Price snapshot for comp #1: Apr 4 Fri $72, Apr 5 Sat $78..."*
- *"My rates for Unit A: Fri $65, Sat $70, weekdays $55"*
- *"Run pricing analysis for Unit A, next 30 days"*
- *"Am I leaving money on the table for Easter?"*

## Key Concept: TCPN

**True Cost Per Night** = `(nightly_rate × nights + cleaning_fee) / nights`

Normalizes across listings with different cleaning fees.
Default assumed stay = 2 nights.

Example: $70/night + $45 cleaning = ($140 + $45) / 2 = **$92.50 TCPN**

## Files

- `schema.sql` — Database schema
- `lib/` — Core libraries (db, normalize, analysis, dates, holidays)
- `scripts/` — CLI scripts for data entry and analysis
- `templates/` — JSON templates for structured data entry
- `reports/` — Generated analysis reports (gitignored)
- `pricing.db` — SQLite database (gitignored)

## Admin Dashboard

Visit `/admin/pricing` to see the latest analysis report with charts.
The dashboard reads from `public/data/pricing-report.json` (generated by `generate-report.js`).
